# yuxuanzhuang8.github.io

Source for my academic website, https://yuxuanzhuang8.github.io. Plain HTML and CSS: no build step, GitHub Pages serves the files as they are.

| File | What it is |
|---|---|
| `index.html` | Main page: bio, research, contact |
| `presentations.html` | Conference presentations (newest first) |
| `style.css` | Fonts, colors, layout |
| `files/Yuxuan_Zhuang_CV.pdf` | CV (replace this file to update it; keep the name) |
| `files/headshot.jpg` | Photo on the main page |
| `sitemap.xml`, `robots.txt` | Help search engines find the site |

**To edit:** change `index.html` (on github.com: open the file → pencil icon → Commit changes). The live site updates in about a minute. After a change, update the "Last updated" line at the bottom of `index.html` and the `<lastmod>` dates in `sitemap.xml`.
